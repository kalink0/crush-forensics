## The Interface

```
┌─────────────────┬──────────────────────────────────┬───────────────┐
│  Filesystem     │         Viewer tabs               │  Properties   │
│  panel (left)   │                                   │  panel (right)│
│                 │                                   │               │
│                 │                                   │               │
└─────────────────┴──────────────────────────────────┴───────────────┘
│  Log panel (bottom, hidden by default)                              │
└─────────────────────────────────────────────────────────────────────┘
```

To float a panel, double-click its title bar or drag it out of the window. A floating panel moves by its title bar, resizes from its edges and corners, and docks back with the **Dock** button in its title bar or **View → Dock … Panel**. Panels are shown or hidden via the **View** menu. Use **View → Reset Panel Layout** to restore defaults.
